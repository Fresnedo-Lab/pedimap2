Subject: Pedimap 2.2.0 is ready – please redraw figures made with earlier versions

Hi all,

A new version of Pedimap 2 (2.2.0) is out. If you have 2.1.2, Pedimap will
offer the update the next time you open it; you can also click ⓘ About →
Check for updates at the top right of the Pedimap window. If you have an
older version, please install it yourself:

1. Go to https://github.com/Fresnedo-Lab/pedimap2/releases/latest
2. Use the "Which file do I need?" table at the top of that page to pick
   the file for your computer, then download and install it.

**Please redraw figures made with earlier versions.** Earlier versions could
draw a parent's line straight through another individual it was not
connected to, so some parentages looked wrong: an individual could appear to
descend from a plant that is not its parent. Pedimap 2.2.0 routes every line
clear of other individuals. If you have used a Pedimap 2 chart or screenshot
in a report, poster or paper, please open the file again in 2.2.0 and export
the figure anew before you use it.

What's new:

- **Export image…** saves the whole chart as PNG, SVG or PDF, ready for
  papers and posters: on a white background by default, with a legend for
  the trait you color by, and with accented names printed correctly.
- **Classic Pedimap style:** each plant is a box with its name on top, as in
  Pedimap 1.x. Switch between **Modern** and **Classic Pedimap** in the
  toolbar.
- **Colored parent lines:** female parent red, male parent blue, and purple
  for selfings and other single-parent descent. Full sibs hang from one ×,
  so families are easy to see (on by default in Classic style; ⚙ to change).
- **Export .dat** saves the whole population, or just the subpopulation you
  are looking at, as a file Pedimap reads back unchanged.
- The low, high and missing colors of a numeric trait can now be changed next
  to **Colour by**.
- Files with more than 1,000 individuals are listed instead of drawn; select
  a plant and click **🔍 Subpop** to draw its relatives. The limit can be
  changed under ⚙.
- Older Pedimap 1.x files with accented names (such as "Élise") now open
  correctly.

If something looks wrong, click ⓘ About, note the version number, and send
it to me with the name of the file.
