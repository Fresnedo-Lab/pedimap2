Subject: Pedimap 2.3.0 is ready – FlexQTL and Binko files, marker genotypes and IBD

Hi all,

A new version of Pedimap 2 (2.3.0) is out. If you have 2.1.2 or later,
Pedimap will offer the update the next time you open it; you can also click
ⓘ About → Check for updates at the top right of the Pedimap window. If you
have an older version, please install it yourself:

1. Go to https://github.com/Fresnedo-Lab/pedimap2/releases/latest
2. Use the "Which file do I need?" table at the top of that page to pick
   the file for your computer, then download and install it.

**Pedimap 2 now reads FlexQTL and Binko files correctly and shows their
marker genotypes and IBD probabilities.** Open the `pedimap.ped` file that
FlexQTL or Binko writes with **📂 Open File**.

**If you opened a FlexQTL file with more than one linkage group in an earlier
version, please open the original file again in 2.3.0.** Earlier versions
mixed up the IBD probabilities of such files: where two linkage groups share
a position (such as 0 cM), only the last group's values were kept. `.dat` and
JSON files saved from such a file by an earlier version carry the mixed-up
data, so start again from the file FlexQTL wrote.

What's new:

- **Marker genotypes:** click a plant to see, under **Markers**, its two
  alleles at every locus, grouped by linkage group, with the genotype code as
  a small colored badge. In FlexQTL and Binko files, hold the mouse over a
  badge to see what the code means (observed, filled in, judged an error, …).
- **IBD probabilities:** under **IBD**, pick a linkage group and a position to
  see which founder allele each of the plant's two chromosome copies most
  likely comes from, with the founder's name and the probability.
- **Color by a marker:** **Color by** now also offers **Genotype code at
  marker…** and **Allele at marker…** (how many copies of an allele each plant
  carries), with a legend on the chart and in exported images. An unknown
  count is shown hatched gray.
- **Marker data**, next to the population name, summarizes the file's loci,
  linkage groups, IBD positions and the genotype codes it uses.
- Parents are labeled as your file names them: "Parent 1" and "Parent 2" for
  FlexQTL and Binko files, "Female parent" and "Male parent" for files that
  say FEMALE and MALE.
- Names on colored plants are always readable: black on light colors, white
  on dark ones, on screen and in exported images.
- Mistakes in a data file are reported with their line number, and problems
  that do not stop a file from loading are shown above the chart.
- Founders without offspring now sit in the founders' row instead of in a
  long column below the pedigree, so such charts are much smaller.

If something looks wrong, click ⓘ About, note the version number, and send
it to me with the name of the file.
