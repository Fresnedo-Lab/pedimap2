Subject: Pedimap 2.1.2 is ready – please install it once

Hi all,

A new version of Pedimap 2 (2.1.2) is out. Please install it yourself once:

1. Go to https://github.com/Fresnedo-Lab/pedimap2/releases/latest
2. Use the "Which file do I need?" table at the top of that page to pick
   the file for your computer, then download and install it.

**Mac users (all Macs, Apple Silicon and Intel):** version 2.1.0 did not
start on Macs. It showed "Cannot reach the Pedimap backend service".
Version 2.1.2 fixes this, so please install it by hand. Intel Mac users:
2.1.0 could not start on your Macs at all; 2.1.2 fixes that too.

From now on, Pedimap 2 will tell you when a new version is available and
can install it for you. You can also check at any time with the ⓘ About
button at the top right of the Pedimap window.

If you could not load a .dat file before, please try again in 2.1.2. If it
still doesn't work, click ⓘ About, note the version number, and send it to
me with the name of the file.

Thanks,
Jonathan
